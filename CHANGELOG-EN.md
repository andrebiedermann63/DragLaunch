# DragLaunch – Version history

Newest version first. As of 27 Nov 2026

## Version 24
- Custom and local icons appear immediately; network icons load separately and no longer hold anything up.
- Network computers, shares and network drives are checked every 20 seconds: reachable shows the real icon, offline shows the globe.
- Network computers are checked faster (1.5 s at most).

## Version 23
- Twelve new click sounds (01 Tick … 12 Tick) replace the previous three.

## Version 22
- Select several tiles with Ctrl+click (Ctrl+A = all). Move the selection together, or copy it with Shift, also into another tab.
- Right-click the selection: open all, colour them together, remove the colour, move or copy to a tab, remove.
- “Add Windows function”: groups can be expanded and collapsed, with “Expand all” and “Collapse all” buttons.

## Version 21
- While the settings are open, red bars show the edge zones right at the screen edge.
- About 50 more Windows settings pages and Disk Cleanup in “Add Windows function”.

## Version 20
- Faster tab switching: tiles appear immediately, icons load in the background.
- Slow tab switches and icons are noted in the log.

## Version 19
- A small gap stays between tiles; colours fill only the tile itself.

## Version 18
- Network shares get a name automatically when dragged in.

## Version 17
- Short message “… is not reachable.” when a network target does not respond.

## Version 16
- Network computers and shell folders can be dragged in reliably.

## Version 15
- “Network” in “Add Windows function” under Folders.

## Version 14
- Tab colours; the text adapts automatically.
- Drag in and open network computers (\\SERVER).

## Version 13
- Labels turn black automatically on light tile colours.

## Version 12
- Tile colours.
- Adjustable menu font size.
- “Send to back” in the menu and with Esc.

## Version 11
- Backups in the “Backup” subfolder.
- Selectable click sound from the “Sound” folder.

## Version 10
- DragLaunch steps back after launching a program.
- The edge zone pauses while certain programs run (e.g. VR).
- Protection against hangs with unreachable network drives.

## Version 09
- Websites get their favicon automatically; “Reload favicon” in the right-click menu.

## Version 08
- After popping up, DragLaunch goes back behind when another window is clicked.

## Version 07
- German and English via language files, switchable in the settings.

## Version 06
- Shortcuts (.lnk, .url) are resolved when dragged in, and their icon is used.

## Version 05
- Store apps and Start menu entries with clean, frameless icons.

## Version 04
- Add Steam games.

## Version 03
- Program icons without white frames.

## Version 02
- Duplicate icons with Shift.

## Version 01
- First numbered version: About window, scalable dialogs.
