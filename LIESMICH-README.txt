DragLaunch - fertig gebaute Version / ready-built version
=========================================================

DEUTSCH

Voraussetzung: Windows 11 und die kostenlose .NET 10 Desktop Runtime
  https://dotnet.microsoft.com/download/dotnet/10.0  ("Desktop Runtime", x64)
  Fehlt sie, zeigt Windows beim Start einen Hinweis mit Download-Link.

Installation:
  1. Vor dem Entpacken: Rechtsklick auf die ZIP -> Eigenschaften -> "Zulassen" anhaken -> OK.
  2. Den Ordner DragLaunch an einen festen Ort entpacken, z. B. C:\Tools\DragLaunch
     (nicht unter C:\Programme - die Einstellungen werden im selben Ordner gespeichert).
  3. DragLaunch.exe starten. Im Menue (oben links) "Mit Windows starten" einschalten.

Update:
  DragLaunch beenden, die neue ZIP in denselben Ordner entpacken und Dateien ueberschreiben lassen.
  Einstellungen (DragLaunch.ini), Backups und eigene Icons sind nicht in der ZIP und bleiben erhalten.

ENGLISH

Requirement: Windows 11 and the free .NET 10 Desktop Runtime
  https://dotnet.microsoft.com/download/dotnet/10.0  ("Desktop Runtime", x64)
  If it is missing, Windows shows a notice with a download link at startup.

Installation:
  1. Before extracting: right-click the ZIP -> Properties -> tick "Unblock" -> OK.
  2. Extract the DragLaunch folder to a fixed place, e.g. C:\Tools\DragLaunch
     (not under C:\Program Files - settings are stored in the same folder).
  3. Start DragLaunch.exe. In the menu (top left) turn on "Start with Windows".

Update:
  Close DragLaunch, extract the new ZIP into the same folder and let it overwrite files.
  Settings (DragLaunch.ini), backups and custom icons are not in the ZIP and are kept.
